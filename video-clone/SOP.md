# X 爆款视频「结构借鉴式」原创化 SOP

原则：只借**结构与节奏**（钩子位置、镜头数、信息密度、字幕节奏、时长），**不搬**画面、台词、BGM、真人肖像。每次付费调用前先报预算并经用户确认。

## 0. 触发与输入
用户回复「克隆 + 编号」→ 取该条视频链接、作者、数据（播放/赞/转/涨速）。建项目目录 `/workspace/video-clone/<编号-日期>/`。

## 1. 拆解（零成本，本地）
1. **取素材（合规优先）**：优先用户自有/已授权文件；否则仅为**个人分析**下载：`hypit download <url> --to ref/source.mp4`（需先 `hypit download prepare`，装 yt-dlp 环境；X 链接是否可下需实测）。下载件仅作分析，**不再分发、不进成片**。下载失败则用屏幕录制/用户提供文件。
2. **镜头**：`hypit media probe`（时长/分辨率/帧率）；`hypit media boundaries` 找切点；`hypit media tile/frames` 出分镜拼图。
3. **台词/文案节奏**：`hypit transcribe`（WhisperX，本机 CPU 可用 small，需先准备本地环境；中文用 `--language zh`），得到逐词时间。无人声则人工列字幕。
4. **输出《拆解表》** `analysis.md`：
   - 数据：发布时间、播放/赞/转/评、涨速、评论区热点；
   - 钩子：前 3 秒做了什么（悬念/反差/数字/冲突）；
   - 结构：段落时间线（0-3 钩子 / 3-x 展开 / 反转 / CTA）、镜头数与平均镜头长度；
   - 字幕：位置、字体风格、逐词高亮、出现节奏；
   - 音频：BGM 类型/BPM、音效点、有无口播；
   - 一句话爆点假设：为什么火；
   - 可克隆性：A 纯字幕/图形可全本地 / B 需生成素材 / C 依赖真人表演或版权素材（建议放弃）。

## 2. 原创化方案（需用户确认）
- **保留**：钩子类型、段落比例、镜头节奏、字幕样式逻辑、时长、CTA 位置。
- **必换**：主题/产品、台词（重写，非翻译式搬运）、画面（重新生成或自拍）、人物（虚拟/AI 角色或用户授权真人）、BGM（免版权/自生成）。
- **可选变体**：换语言（中/英）、换人物、换竖横屏、换 CTA。
- 产出 `plan.md`：新选题、新脚本（逐段时长）、分镜表、风格板、预估成本、风险点。至少给 2 个方向让用户选。

## 3. 素材清单
| 类别 | 来源 | 备注 |
|---|---|---|
| 脚本/字幕 | 自写 | `hypit estimate` 估时长 |
| 人物图 | AI 生成虚拟人（GPT Image / Seedream / nano-banana 等）或用户授权照片 | 不得用名人/他人肖像；真人需书面授权 |
| 视频段 | AI 生成（Seedance/Pixverse 等）、用户自拍、授权素材 | 记录来源与许可 |
| 换人原视频 | 仅限用户自有/已授权视频 | 禁止对 X 上他人视频直接换脸/换人后发布 |
| 配音 | TTS（ElevenLabs/Fish/MiMo 等）或用户录音 | 需 key，付费 |
| BGM/音效 | 免版权库或生成 | 保留授权证明 |
| 字体 | hypit 内置 fontsource（开源字体） | |

## 4. 成片路径与成本
**路线 A（零成本）**：hypit 编排 + 本地 HTML/Chromium 渲染字幕、图形、排行榜、转场 + 用户自有素材。无需 key。
**路线 B（生成素材）**：A + 图像/视频生成（经 HypiHub 或自有 key）。参考官方示例单条约 $1–1.2（20 秒级，Seedance 720p + 图像）。
**路线 C（换人）**：在用户有权使用的视频上，用 fal 的 Wan 2.2 Animate Replace（480p 约 $0.04/秒，需 FAL_KEY；价格以 fal 页面当时为准）。10 秒 ≈ $0.4，另加人物图约 $0.04–0.1。hypit 内置 Provider 无该模型，需单独调用 fal API 后把结果当文件素材导入 hypit 合成。
流程：`hypit` 写 SVML/Run → `hypit plan` 看将执行的工作 → `hypit pricing` 看费率 → **向用户报预算并确认** → `hypit build --follow` → `hypit get` 导出 → `ffmpeg` 转码（竖屏 1080×1920/H.264/AAC）。
迭代上限：默认每条最多 2 轮重生成；超预算即停并汇报。

## 5. 合规检查表（交付前逐项勾）
- [ ] 画面无原视频帧/截图；构图与原片不构成实质相似
- [ ] 台词原创，非逐句改写；无原作者独有梗/口头禅整段搬运
- [ ] 无真人肖像（原视频人物、名人）；若用真人，有书面授权
- [ ] AI 人物非真人相似；声音非克隆他人
- [ ] BGM/音效/字体/图片均有授权或免版权
- [ ] 无商标、品牌 Logo 误用；无虚假宣传、医疗/功效夸大（美妆类尤其注意）
- [ ] 按平台要求标注 AI 生成内容
- [ ] 来源链接与参考关系记录在 `provenance.md`（仅内部存档）
- [ ] 下载的原视频未被转发、未进入成片
- [ ] hypit 导出物保留其 Logo/版权信息（许可证条款 1c，如界面有展示）；不得将 hypit 作为多租户/对外 SaaS 提供

## 6. 交付物
- `analysis.md` 拆解表；`plan.md` 原创方案（含成本）；`provenance.md` 素材来源与授权
- 成片 `final_9x16.mp4`（+ 可选 16:9、不同语言/人物变体）
- 封面图、字幕文件 `.srt`、发布文案与话题标签草稿
- 成本明细（实际花费 vs 预算）与 hypit 项目目录（可再编辑）
交付给用户确认，**不自动发布**。
